# Kicad Version

The project has been migrated to Kicad with some small changes
* All SMD parts (except the RAM) were moved to the bottom side.
* Added a single gate option for U4.
* VBB option was implemented as a solder jumper. This makes it possible to switch without removing the whole adapter from the motherboard.
